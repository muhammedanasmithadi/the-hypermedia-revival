Hypermedia: the architecture we forgot

A plain-language course on hypermedia systems: what the web was built to do, and why the pattern still wins.

Begin with Section 01 View all sections

What this course is

The web was built as hypermedia: documents that carry the next move a client can make. Each section is a self-contained page, with machines you can run in your own browser.

  • 05 Ask without harm. Repeat without doubt. Sort HTTP methods by harm and repeatability, then replay a dropped connection.
