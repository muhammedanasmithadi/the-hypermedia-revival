Hypermedia: the architecture we forgot

A plain-language course on hypermedia systems: what the web was built to do, and why the pattern still wins.

course home sections 01-04 live

The web was built as hypermedia: documents that carry the next move a client can make. This course shows that loop at work, and why the industry drifted toward JSON-only APIs. Each section is a self-contained page, with machines you can run in your own browser.

  • 01 The machine that prints its own manual → One loop: request, document, choice, next document.
  • 02 How the idea got lost → From two words in 1965 to a data-only contract in 2011.
  • 03 Two architectures on the same table → The same feature, built two ways: a document or a JSON feed.
  • 04 The status line names what happened → Read the five classes of every reply in three digits.
